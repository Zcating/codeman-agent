## Scenarios (the contract — 验收标准)

### S1 — `deriveLabelFromPath` 工具
- Happy: `C:\foo\bar` → `"bar"`
- Edge: `C:\` → `"Untitled workspace"`
- Edge: `/` → `"Untitled workspace"`
- Edge: `foo` (无 separator) → `"foo"`
- Edge: `C:\foo\bar\` (trailing slash) → `"bar"`
- Edge: `/home/me/foo` → `"foo"`
- Surface: `src/shared/lib/derive-label-from-path.test.ts` vitest 输出

### S2 — `appStore.addWorkspace(rootPath)` 同步方法
- Happy: 新路径 → 创建 ws + write to state + return new ws
- Dedup: 同 root_path 已存在 → 不创建, return existing ws
- Empty input: `addWorkspace("")` → return null (validation)
- 默认值: id = uuid, label = basename, enabled = true
- Side effects: `settingsSaver.scheduleSave()` 被调 (mock 验证)
- Surface: `src/shared/stores/app.store.test.ts` (or extension)

### S3 — HomeAgentForm 新布局
- Textarea 在 workspace picker 之前 (DOM 顺序验证)
- workspace picker 200px fixed (Tailwind class verify)
- LLM picker 200px fixed (Tailwind class verify)
- Send 单独一行 right-aligned (CSS layout verify)
- LLM picker 与 ChatView ProviderSelect 同源 (复用 buildEnabledProviders + CodemanGroupSelect)
- Surface: `home.test.tsx` + 实际 DOM snapshot via @solidjs/testing-library

### S4 — Home Add Workspace Action slot 接 picker
- Action slot onClick 调 `appStore.pickWorkspacePath()` (mock 验证)
- Picker 成功 (返回 `/fake/path`) → 调 `appStore.addWorkspace(path)` → 自动 setDraftWorkspaceId + setLastUsedWorkspaceId + focus textarea
- Picker 取消 (返回 null) → 不调 addWorkspace, dropdown 关闭
- 同 root_path 重复 → 静默忽略,自动选已有
- Surface: `home.test.tsx` 模拟 user click flow

### S5 — Home LLM picker 集成
- 显示 enabled providers (复用 buildEnabledProviders)
- 切换 model → `appStore.set({ default_llm_provider_id: provider.id })` + `settingsSaver.scheduleSave()`
- Surface: `home.test.tsx` + `appStore.state.value.default_llm_provider_id` 验证

### S6 — e2e Playwright
- Home 加载 → workspace picker + LLM picker + Send 三件套可见
- 0 workspace → CTA 显示
- 2+ workspace → LLM picker 显示 first provider's default model
- Surface: `vp run e2e` 全 pass
