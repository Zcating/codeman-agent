# v2.2.0 — D8-W Workspace Chat-Ownership Migration

## ⚠️ BREAKING CHANGES

### Workspace data not migrated
Existing workspaces stored in `Settings.workspaces[]` are **not migrated** to the new SQLite table. After upgrading, re-add your workspaces via Home → "+ Add new workspace…".

### Deleting a workspace deletes ALL conversations in it
When you delete a workspace (sidebar hover → Delete), all conversations in that workspace are CASCADE-deleted. Always review before deleting.

### Workspace behavior changes
- **`enabled` field removed**: All workspaces always active. Sandbox enforcement unchanged.
- **`root_path` immutable**: To change a path, delete and re-add.
- **WorkspaceCard removed**: Workspace management via sidebar hover (rename/delete) and Home picker (add).

## What's new
- Workspace data in SQLite (faster, more reliable)
- Sidebar rename/delete via hover buttons
- Confirmation dialogs for destructive operations
